# Orçamento base V0.71.6

- Uma obra pode possuir várias revisões de orçamento, mas somente uma pode ser o orçamento base.
- Somente revisões aprovadas podem ser definidas como base.
- Novas solicitações de materiais usam exclusivamente o orçamento base para gerar centros de custo.
- Um orçamento pode ser excluído enquanto não possuir solicitações lançadas nos centros de custo que ele gerou.
- Ao definir uma nova base, a revisão anterior permanece disponível para histórico e seus lançamentos continuam preservados.
